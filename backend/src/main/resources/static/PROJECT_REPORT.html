IOB Digital KYC Banking System

AI-Powered Know Your Customer Verification Platform

Project Report | July 2026

1. Executive Summary

A full-stack AI-powered Digital KYC (Know Your Customer) banking application built for Indian Overseas Bank (IOB). The system automates identity verification using OCR, QR code parsing, facial recognition, liveness detection, anti-spoofing, and deepfake detection. Deployed on Railway with MySQL database, Java Spring Boot backend, Python Flask AI/ML server, and a responsive HTML/CSS/JS frontend.

2. System Architecture

Backend (Java Spring Boot)

  • JWT Authentication & Spring Security
  • Role-Based Access Control (ADMIN, MANAGER, OFFICER)
  • REST API endpoints for KYC workflow
  • Branch entity & account management
  • Profile photo with base64 fallback
  • Rate limiter (5000 req/min)

AI/ML Server (Python Flask)

Frontend

Infrastructure

3. Features Implemented

3.1 KYC Verification Flow

  1. Step 1 - Personal Details: Name, DOB, Gender (auto-filled from Aadhaar OCR)
  2. Step 2 - Document Upload: Aadhaar & PAN card upload with OCR extraction + QR verification
  3. Step 3 - Liveness & Face Verification: 8 challenge types (wink, mouth open, look up/down, nod, smile, blink, turn head) + liveness + anti-spoofing + deepfake detection
  4. Step 4 - Review & Submit: Summary with QR cross-verification results

  • Inline form validation with error clearing

4. Verification Gate Logic

Confidence-based override system:

GateThresholdBehavior
Face Match≥ 50% similarityRequired for pass
LivenessAll 8 challenges passedRequired for pass
Anti-SpoofingSPOOF_THRESHOLD = 0.45, CONFIDENCE = 0.35Advisory only if face ≥ 50% + liveness passed
DeepfakeDEEPFAKE_THRESHOLD = 0.70Advisory only if face ≥ 50% + liveness passed

Override Rule: If face similarity ≥ 50% AND all liveness challenges pass, spoof/deepfake results are overridden (advisory only).
